CARE BEAUTY BY MARY — SITE VITRINE PREMIUM
==========================================

CONTENU
- index.html         : accueil et présentation de l'institut
- services.html      : page des univers de soins
- avis.html          : page dédiée aux avis clients
- rendez-vous.html   : formulaire de rendez-vous WhatsApp
- style.css          : design premium responsive
- script.js          : menu mobile, formulaire et boutons WhatsApp
- assets/            : image de référence du bouton rond fournie

OUVRIR LE SITE
1. Décompressez le dossier ZIP.
2. Ouvrez index.html avec Chrome, Edge ou Firefox.
3. Pour publier le site, envoyez tous les fichiers en conservant la structure des dossiers vers votre hébergeur.

WHATSAPP
Le numéro utilisé est le numéro fourni dans le brief : +225 07 05 02 17 80.
Il est défini dans script.js dans la constante WHATSAPP_NUMBER.

À SAVOIR
- Le formulaire prépare un message et l'ouvre dans WhatsApp : le visiteur doit encore appuyer sur Envoyer.
- Il ne s'agit pas encore d'un système de réservation avec calendrier, base de données ou espace administrateur.
- Les images d'ambiance sont chargées depuis Unsplash ; une connexion Internet est nécessaire pour les afficher.
- Vérifiez les prestations exactes, les horaires et le numéro avec la propriétaire avant la mise en ligne.
- Le site n'intègre pas encore de tarifs, car aucun tarif n'a été fourni.
